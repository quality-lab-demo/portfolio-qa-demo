# Portfolio QA Demo

An original, self-contained demo site for recording Chapter 2, Lesson 11.

Pages:

- `before.html` — intentionally slow, inaccessible, and non-responsive
- `after.html` — optimized and accessible comparison
- `error-states.html` — form error, dead button, coming-soon, 404, and copy QA
- `qa-checklist.html` — final QA progress screen
- `slow-interaction.html` — deliberately overloaded motion and input-lag comparison
- `optimized-interaction.html` — the same interaction with long tasks and excessive motion removed

The site uses no third-party images, fonts, scripts, or copied interface assets.
